\section{Contribución}

Este proyecto eliminará barreras técnicas y económicas que actualmente limitan el acceso a herramientas profesionales en la formación en ingeniería de control. Permitirá a los estudiantes utilizar el sistema de tanques interconectados sin necesidad de conocimientos técnicos avanzados.\\ 
Además, servirá como plantilla para futuras innovaciones e implementaciones en otras plantas de control dentro del laboratorio.
